# Cuaderno Técnico 📓

Apuntes de desarrollo Full-Stack organizados por categoría. Cada sección cubre conceptos, ejemplos de código y buenas prácticas recopilados durante el proceso de aprendizaje y trabajo real.

## Categorías

| Sección | Temas |
|---|---|
| ⚙️ **Backend** | NestJS, Django, APIs REST, Bases de Datos, TypeScript |
| 🎨 **Frontend** | Desarrollo Web, React, GSAP, Diseño UX, Frameworks |
| 🛠️ **DevOps** | Git & GitHub, AWS, Lenguajes, Tecnologías |
| 🏗️ **Arquitectura** | MVC, Desarrollo de Software |
| 📋 **Metodologías** | Ágiles, Scrum, Kanban |
| 📦 **Logística** | Gestión, cadena de suministro |
| 🤖 **IA** | Inteligencia Artificial aplicada al desarrollo |

:::tip Cómo usar este cuaderno
Usa el menú lateral para navegar entre temas. Cada apunte incluye definiciones, bloques de código listos para copiar y referencias a temas relacionados.
:::
